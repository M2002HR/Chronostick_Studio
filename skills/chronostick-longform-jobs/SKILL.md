# ChronoStick long-form jobs

Inspect the installed `comfy-video-automation` request model and current capabilities before constructing jobs. The project profile `h3-long-5s-14step-16x9` is in `docs/longform/format-contract.md`. The current service accepts `profile: youtube_shorts_hq` as an API enum, with explicit long-form overrides: `aspect_ratio: 16:9`, `1024×576`, `megapixel: 0.6`, `duration_seconds: 5`, `fps: 24`, `steps: 14`, `sampler: res_multistep`, `scheduler: beta`, `lightning: false`, and `ref_image_size: match`. Never rely on the service profile's Shorts defaults. A representative final-setting capability probe must pass before a large queue.

Write a complete `automation/job-plan.json` with one ordered slot, one or two existing references, a revision and a project seed for every timed clip. Use `python scripts/build-longform-jobs.py EPISODE --dry-run` and then the same command without `--dry-run` to create `automation/jobs/clip-NNN.json`. Each job names an existing pure prompt and references matching `<Picture 1>` through `<Picture N>` exactly. The builder derives explicit unique fixed seeds from the episode project seed and slot; retain the same seed on retry unless failure analysis calls for a recorded override. Output paths and `job_identity` include an immutable `-rNNN` attempt and never collide with existing raw/editorial media. Keep both the raw 124-frame result and exact 5.000-second editorial normalization, with no time stretch. Audio remains enabled SFX-only with music, speech and narration false; no automatic concat or upscale.

Run `python scripts/validate-longform.py EPISODE` and a live-service batch dry-run. Check JSON schema, paths, asset hashes, ordered tags, dimensions, seed uniqueness, output collisions, maps/text exceptions, exact no-music sentence and every planned slot. Divide the queue by reviewed chapters only after the *whole* plan and job set pass; `python scripts/stage-longform-chapter.py EPISODE chapter-id --first N --last M` copies a contiguous range into a separate batch folder and records source hashes. Do not let a partial chapter hide missing later slots. Save preflight results and resource estimate. Job preparation, chapter staging and dry-run do not authorize costly submission; `$chronostick-batch` handles only an explicitly authorized launch and monitoring.
