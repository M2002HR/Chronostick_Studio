# ChronoStick long-form assets

Read the approved shot plan, identity/world/state ledgers, map manifest, text-event ledger, reference-video analysis when supplied, and shared style authority. Make anchors from the approved ChronoStick adaptation in the shot plan, not raw reference-video frames. Reuse a locked compatible asset first. Count *episode-wide* anchors by genuine scene/state/viewpoint coverage, not by a fixed quota; each H3 job still normally uses one, occasionally two, ordered full-frame references.

For each real historical person, find institutional period portraits or descriptions and archive URLs, attribution and uncertainty. Extract a few persistent ChronoStick cues: silhouette, hair/facial hair, costume cut, proportion and a documented accessory. Create a single-person identity anchor, review it at full size and thumbnail size, then derive group/scene anchors. An unknown individual's design is a consistent *interpretation*, not a claimed likeness. Apply the same identity/count discipline to animals, vehicles, uniforms, buildings and props. Every visible pixel remains in one illustrated stick world; reject photographic maps, hands, water, animals or backgrounds.

For each map, research the depicted date and political status. Record source geometry, coastline and borders, legend, territorial ownership, route, annotation and zoom sequence. Produce an original ChronoStick map family that keeps shapes and symbols consistent from world to region to local view. Show relevant characters as stable map tokens only at their narrated locations; record which moves are documented and which are broad explanatory routes. Prefer a rich, readable physical illustrated chart inside the same stick world over a bare flat card, and do not add complexity that hides geography. A map anchor can bear only the approved exact labels. For text-bearing anchors, confirm the Spanish spelling/diacritics and place it where H3 can keep it stable; the rendered video still needs frame-by-frame approval. Every finished map, clock, chart and text clip is generated by H3; these reference images are still inputs only.

Write pure image prompts under `prompts/image/episodes/<id>/` and save immutable assets under `assets/episodes/<id>/references/` using `-rNNN`. Record selected path, hash, provenance, review and exact supported shot IDs in `plan/reference-manifest.json`. At the gate, every planned shot must have real visual authority for its people, action, location, story phase, props, map and text; a nice-looking reference without semantic coverage does not pass. Do not spend on an entire anchor set before the first representative identity/map/text probes are reviewed.

Before approving a ten-minute anchor set, count distinct active references, maximum reuse, consecutive same-anchor runs and distinct views in successive one-minute windows. Inspect a voice-led animatic, especially exposition and aftermath passages. Add alternate camera angles or scene distances for repetitive stretches while retaining the same character clothing, architecture, coastline, map pins, ship count, text style and damage state. An imagegen variant that moves a location marker or silently changes identity is rejected even if it improves visual variety.
