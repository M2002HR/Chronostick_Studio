# Purpose

This file permanently defines the recurring late-18th-century French armed guard / field sentry used throughout ChronoStick Studio productions.

The character is especially important for Episode 001, where armed guards visually communicate that the potato field is being protected and therefore appears valuable to nearby villagers.

This is NOT a specific documented historical individual.

This is NOT a specific named military regiment.

The design must communicate:

- official authority
- discipline
- armed protection
- late-18th-century French historical context
- visual seriousness

without inventing unverified regiment-specific insignia.

Once approved, this Character Sheet becomes the source of truth for:

- head shape
- body proportions
- hat
- hair
- coat
- uniform color blocking
- belts
- footwear
- musket
- equipment
- stance
- expression system
- patrol movement
- guarding poses

The generation model must not independently redesign this guard between shots.

# Character Identity

## Internal Character Name

French Guard A

## Production ID

CST-CHAR-004

## Narrative Function

This character represents an armed late-18th-century French guard / sentry.

Primary uses:

- guarding the potato field
- standing at field boundaries
- walking short patrol routes
- controlling access
- leaving the field at night
- appearing in background security positions
- visually reinforcing the perceived value of the crop

The guard should communicate authority immediately even when shown for less than one second.
